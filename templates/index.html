Run set-up

These are the base inputs. With a case selected, fields with an orange edge are set by the case at run time (titre scale, step yields, Protein A DBC and capacity); the upstream mode is IDB and the curve shape follows the case settings. The Protein A column volume is column_capacity_g ÷ DBC_gL from these inputs.

Parameters (defaults are illustrative — replace with site data)

Types: qp_step (factor; scales the titre curve in IDB mode), feed_glucose_step (factor) and vcd_sensor_bias (bias) for the legacy model. Example: [{"type": "qp_step", "day": 10, "factor": 0.85}]
HMB = mass balance of the last run (the model has no energy balance). Per batch from the hourly simulation; per year = per batch × the case's batches per year.
